2. TOOLING (research/higgsfield-2026-10-08/tools; selftest 18/18 PASS)
   • loop_interval.py closure — whole start=end clip: last frame duplicate or continuation (picks
     b = N−1 or N), anchor joint step, direction in/out, speed across the joint, live share per
     window, slowest half-second, sub-pixel product shift, motion_regions gate on the loop ×3.
   • cut --closed now accepts b = N (whole clip incl. the last frame when it is a continuation);
     manifest records mode and the real loop length.
   • adopt_release.py — adopts ONE accepted cut folder: copies reveal/loop/posters into
     ios/Salini/Resources, rewrites only that collection's CinemaRelease entry (version, names,
     measured loopFrames, source), lists the previous release's now-unreferenced files
     (--remove-old deletes them only if no Swift source/project.yml mentions them). Dry run by
     default. Verified dry run for Greca (diff printed, nothing written).
   • regions.json: closed takes share the open compositions; new "greca-seed" preset (Seedance
     framing differs); the calm far-horizon band removed from Greca presets (calm by design, not a
     defect).
