3. Референсы и промпты

Нужен чистый master reference с полностью читаемым силуэтом. Для Salini сохраняем форму чаши, ширину борта, основание, слив, материал и пропорции. Дополнительный ракурс добавляем только если он достоверно показывает тот же продукт. Не смешиваем четыре похожие, но разные ванны.

start_image задаёт первый кадр; end_image — конечную композицию; image reference / Element — идентичность или художественный ориентир; video reference — движение или источник редактирования. Эти роли нельзя подменять. В Canvas прямое подключение изображения к Kling трактуется как первый кадр; для идентичности нужен правильно сохранённый и указанный Element. Правила Canvas.

Для одного плана достаточно короткой точной режиссуры. Для нескольких — отдельно описываем план, положение камеры и переход. Полезная структура: сцена → первый кадр → что движется → физика → камера → свет → ограничения → звук. Небольшой набор целевых референсов предпочтительнее максимального числа разнородных картинок. Официальное руководство Seedance 2.5.

SCENE: точное изделие из reference в утверждённом окружении.
MOVEMENT: где, в каком направлении, с какой амплитудой и одновременно ли.
RIGID: что обязано оставаться неподвижным и геометрически неизменным.
CAMERA: один фиксированный план; кадрирование и перспектива постоянны.
PHYSICS: вес ткани, масштаб волн, причины движения и отражений.
LIGHT: один согласованный свет; без пульсации экспозиции.
ENDING: движение продолжается, без остановки перед концом.
AUDIO: выключен параметром модели.

Это наш рабочий шаблон, не универсальная магическая формула. «8K, cinematic, ultra premium» не заменяет описания действия. Для сравнения меняем одну существенную переменную: модель, тип опоры или движение. Если меняем сразу промпт, кадр и модель, результат нельзя честно приписать одному фактору.

4. Почему живой луп — отдельная задача

Одинаковые первый и последний кадры дают совпадение положения, но не гарантируют непрерывную скорость. Наши пробы показали зависимость от сцены: Greca и Opera сохранили движение с одинаковыми anchors, Aria почти замерла, а Ninfea стала слишком спокойной. Поэтому правило «start=end всегда замораживает» неверно. Для воды этот способ оказался удачным; для ткани потребовался отдельный сгенерированный мост между двумя разными фазами живого дубля.

  1. Сначала непрерывный дубль. Вода, листья и отражения должны двигаться уже в начале и до конца; широкая движущаяся область должна читаться на телефоне.
  2. Разделить необратимое и циклическое. Рост лозы, наполнение и превращение — вступление. Сформировавшийся сад, вода и колыхание — повторяемый хвост. Нельзя пустить рост назад ради петли.
  3. Искать естественный период. Из одного дубля взять intro [0,a), затем loop [a,b). Начало лупа продолжает собственное вступление; проверить остаётся стык b→a.
  4. Сравнивать не только изображения. Сопоставить фазу волн, скорость и направление ткани, экспозицию, ригидные края. Сходство кадров не является достаточным критерием.
  5. Если шов не проходит — сгенерировать мост. Извлечь точные последний и первый кадры выбранного интервала; передать их как start/end короткого видео. В Kling 3.0 минимальная длина — 3 секунды. Проверить оба новых стыка, скорость и движение внутри моста. Дублирующиеся конечные кадры удалять только после измерения: у Kling Greca последний кадр оказался продолжением, у Seedance — дубликатом. Слайды с opacity, обратное движение и замороженный хвост исключены.
  6. Проверить три полных повтора в приложении. Без controls, чёрного кадра, задержки декодера и растяжения. Смена коллекции перезапускает вход; Reduce Motion может показывать постер по системной настройке.

Инженерные инструменты Opus лежат в loop_interval.py. Они измеряют движение в окнах по 0,5 секунды, шов, скорость, направление и зоны изделия. Численные пороги — диагностика, а не замена художественной приёмки. Изменение блика на поверхности не тождественно деформации: сомнительный регион проверяем по контурам.

В мостах Aria и Ninfea использована плавная коррекция только низкочастотного тона/цвета для совпадения с исходным дублем. Движение остаётся сгенерированным: нет растворения между неподвижными картинками, обратного проигрывания или переноса контуров. Инструмент отказывает в такой коррекции при большом структурном расхождении — тогда нужен новый дубль. У Ninfea задняя часть сада спокойнее передней листвы и воды; это наблюдаемое ограничение принятого варианта.

5. Кредиты и права запуска

На старте проверки подключённый аккаунт показал 889 кредитов, Plus, unlim_available=false. Это снимок до новых генераций. Состояние trial и бесплатные счётчики хранятся отдельно: их нельзя просто прибавить к основному балансу.

Фактическая серия: 11 завершённых заданий — 9 полноценных дублей и 2 трёхсекундных моста. Потрачено 179 кредитов; после серии подтверждено 710. Десять запусков Kling стоили суммарно 123, один Seedance — 56. Это стоимость исследования вместе с отбракованными вариантами, а не цена четырёх готовых фильмов.

Обычный web Unlimited предназначен для ручного использования сайта; он не распространяется автоматически на MCP/CLI/Canvas. При этом живой MCP описывает отдельные trial-unlim и free-generation entitlement. Поэтому для конкретного запуска проверяем balance + estimate и разрешённые flags, а не обещание из карточки подписки. Автоматизация веб-безлимита для обхода тарификации не используется. Официальные границы Unlimited.

Developer API — отдельный продукт с ключом, собственным долларовым балансом и каталогом. MCP использует подключённый аккаунт и его кредиты. Для текущих фильмов API-ключ не нужен. Разница API и MCP.

  • Всегда quote перед новой конфигурацией; явно выключать ненужный звук, выбирать нужную длительность и разрешение.
  • Не делать upscale всех проб. Сначала геометрия, движение и композиция; затем разрешение и кодирование.
  • Одна пилотная сцена → вывод → независимые сцены. Batch ускоряет ожидание, но столь же быстро размножает ошибку.
  • Для оценки цены без загрузки достаточно параметров. Quote с HTTPS-reference может сам загрузить файл; сохраняем подтверждённый UUID и переиспользуем его.
  • Технический failed и художественно плохой completed — разные случаи. Возврат при техническом сбое проверяем по фактическому балансу. Диагностика сбоев.

6. Надёжная работа через плагин

  1. Уточнить входы и deliverable; проверить текущий workspace. Не менять workspace или настройки проекта без причины.
  2. Проверить предпочтение auto_create_project. Здесь false: папки/проекты автоматически не создаём.
  3. Выбрать model ID из каталога; изучить roles, enum, длину, формат. API-идентификаторы не копируем в MCP.
  4. Сохранить запрос и quote, отправить один раз, записать job ID сразу.
  5. При timeout исход неизвестен: сначала найти/дождаться исходного job, не отправлять платный дубликат.
  6. Уважать poll_after. Прямой generate уже создаёт обновляемый виджет; повторный display не ускоряет генерацию.
  7. Скачать результат для монтажа и интеграции; записать SHA-256, длительность, FPS, размер, модель, параметры, итог QA.
  8. Хранить исходный клип отдельно от финального. Реестр app-assets обязан ссылаться на фактически принятый файл, а не на последнее совпадение по имени.

Canvas удобен для видимого графа экспериментов; прямой MCP — для текущей работы; собственный API — для будущей серверной генерации персональных предложений. Секреты API никогда не вшиваются в iOS. Для предложений Salini сначала формируется подтверждённая спецификация заказа; генеративная часть украшает историю, но не сочиняет цену, размеры и комплектацию.

Практическая проба: первый Greca Kling Pro, job a05818b2-dd50-46fd-85e5-cba267fa8715, вернул 1244×1660, 24 fps, 193 кадра. Запрос не задавал ratio; 3:4 получен по референсу, хотя enum модели перечисляет другие форматы. Это наблюдение одного запуска, не гарантия всех будущих. Вода заметно движется до конца; исходный шов повторения ещё не принят. История экспериментов — generation-runs.json.

Сравнение Greca завершено: оба matched-keyframe дубля дали живую петлю. Kling 3.0 Pro: 1244×1660, 8 секунд, 12 кредитов; движение примерно в 60–65% анализируемых участков. Seedance 2.5: 834×1112, 8 секунд, 56 кредитов; 44–52%. Для этой конкретной сцены выбран Kling: больше читаемого движения и разрешения при меньшей стоимости. Это сравнение одного дубля каждой модели с общим исходным кадром и заданием, а не универсальный рейтинг или доказательство стабильного преимущества.

8. Что пока не доказано

  • Нет сравнительного бенчмарка всех 127 записей и нет универсальной «лучшей модели».
  • Нет гарантии бездефектного seamless loop одной текстовой командой.
  • Не проверены в работе hosted 3D Jutsu, локальный Blender Bridge, Video Relight, Katana, голосовые и рекламные workflows.
  • Часть маркетинговых статей расходится с живым каталогом: число аудиомоделей, формат upscale, Unlimited. Для запуска приоритет у конкретной схемы и ответа сервера; расхождения не замалчиваются.
  • Сгенерированный файл ≠ встроенный файл ≠ загруженная TestFlight-сборка. Эти три состояния фиксируются отдельно в релизном отчёте.
