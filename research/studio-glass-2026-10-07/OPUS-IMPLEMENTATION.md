7 октября 2026. Рабочая копия `~/.codex/worktrees/salini-studio-glass/Salini`, ветка `codex/salini-studio-glass`.

Ни commit, ни push, ни публикации не было. Модели, веб-служба и локальный сервер не запускались. Исходная папка Salini, iOS, фильмы и Balance не тронуты.

## Направление

- **Палитра.** Холодный фарфор `#f3f5f8`, белая поверхность, графит `#1b2026`, спокойный синий акцент `#2b62c9`. Оливковых, бежевых и радужных пятен нет.
- **Стекло — только на навигации и элементах управления над содержимым:**
  - шапка;
  - мобильная панель быстрого перехода;
  - панель подключения поверх фотографии;
  - метки «до / после»;
  - ручка разделителя;
  - панель обрезки;
  - кнопка в пустом состоянии.

  Внутри стекла все кнопки сплошные. Колонка настроек, панель цвета, карточки «Доступ» и мобильная панель подключения (она не лежит на фото) — обычные поверхности.
- **Шрифт** — системный стек SF / system-ui. Внешних шрифтов, CDN и аналитики нет.
- **Фотографии.** Только официальные `aria.jpg` и `interior.jpg` из `ios/Salini/Resources`. Before/after не выдумывался. Подпись к интерьеру прямо говорит: «Фотография из каталога Salini… а не результат обработки».

**Изображение и управление:**
- **Изображение.** Масштаб считает `app.js`; CSS картинку не растягивает и не обрезает. Окно просмотра `clamp(320px, 54vh, 680px)`, на десктопе прилипает под шапкой. Фон окна нейтральный `#e4e8ed`, без цветового оттенка.

При ширине ≤ 560 px убирается подпись «Render Studio». При ≤ 360 px убирается «На … Mac», потому что строка о конфиденциальности в форме остаётся.

**`app.js` — автопрокрутка на телефоне (запрос Codex QA):**
- добавлена `revealImage()`: при ширине ≤ 760 px вызывает `$('editor').scrollIntoView({block:'start'})`;
- при `prefers-reduced-motion` прокрутка мгновенная, иначе плавная;
- шапку и панель быстрого перехода учитывает единственный отступ `scroll-margin-top: 128px` — верх редактора оказывается примерно на 128 px от верха окна;
- вызывается после успешной загрузки, при входе в обрезку и в восстановление детали;
- восстановление сеанса при открытии страницы прокрутку **не** вызывает.

## Тесты

Запущены локально, без сервера, моделей и сети. Python — интерпретатор из `.venv` исходной папки, код — из рабочей копии:

```
python -m pytest -q tests                 → 29 passed
node --test tests/pages_connect.test.mjs  → 8 passed
```

**`tests/pages_connect.test.mjs`** — неизменённый `connect.js` в `node:vm` с поддельными fetch, таймерами, localStorage и crypto. Приглашение — заглушка `TEST-INVITE-NOT-A-SECRET`.
- `{url: null}` → офлайн, повторная проверка через 30 с, «Открыть студию» скрыта.
- Сбой сети, `online:false`, ошибка HTTP, чужое `app` → офлайн.
- Здоровая служба → один `location.replace`. Приглашение и ключ посетителя только во фрагменте `#`, в query ничего нет. `/health` запрашивается с `credentials: 'omit'`.
- Недопустимые адреса (http, чужой домен, путь, порт, учётные данные в URL, вложенный поддомен, `javascript:`) → `/health` не запрашивается.
- Повтор: кнопка блокируется на время проверки, второе нажатие игнорируется, затем переход.
- Хранилище заблокировано (Safari private) → ключ генерируется, подключение работает.
- Сохранённый ключ используется повторно, новый сохраняется.
- Ссылка без приглашения → пустой `invite`.

**`tests/test_studio_contracts.py`:**
- хэш `connect.js` и наличие `connection.json`;
- контракт id и `hidden` в Pages, `robots`/`referrer`;
- сопоставление цветов индикатора (hex и `rgb()`);
- нет сторонних запросов; бюджет ассетов (Pages ≤ 2 МБ, Web ≤ 1 МБ); указанные файлы ассетов существуют;
- каждый id, к которому обращаются `app.js` и `online.js`, есть в разметке;
- наборы `data-mode` и `data-look`;
- структура `.header-right` и `#about`;
- строки замены из `online_app.py` встречаются в `web/index.html` ровно один раз (пары извлекаются из исходника, а не копируются в тест);
- запасные варианты для стекла и reduced-motion, reduced-transparency, focus-visible.

Статический тест `revealImage`, который искал строки в `app.js`, удалён по замечанию Codex: он копировал реализацию. Поведение автопрокрутки Codex проверяет в браузере.

## Визуальная и доступностная проверка

**Как проверял.** Headless Chrome на файлах, без сервера. Мобильные ширины — через iframe точного размера, потому что окно headless Chrome не уже ~500 px. Редактор снимался из временной копии `web/` в scratchpad с относительными путями. Его проверено только пустое состояние: без службы `/api` недоступен. Онлайн-шапка — с имитацией серверных замен.

| Ширина | Pages | Web |
|---|---|---|
| 320 (×568) | кнопка подключения в первом экране | шапка помещается вместе с «Ссылкой на студию» |
| 390 (×844) | в первом экране | быстрый переход, одна колонка |
| 768 | фото 16:9, текст ниже | две колонки, фото в пустом состоянии |
| 1280 / 1440 | фото справа, ванна свободна | редактор и стекло шапки |

- **Контраст (WCAG):**

  | Пара | Контраст |
  |---|---|
  | основной текст на фарфоре | 15:1 |
  | вторичный текст | 5,8:1 (на белом 6,3:1) |
  | дополнительные подписи `--faint` | 4,96:1 (поднят с 3,8) |
  | акцентный текст | 5,2:1 |
  | белый на акценте | 5,7:1 |
  | выбранные кнопки | 6,6:1 |
  | ошибки | 7,0:1 |

- **Клавиатура:** ссылка «К подключению», `:focus-visible` синего цвета на всех элементах, якоря быстрого перехода. Порядок фокуса совпадает с визуальным: DOM не переставлялся.
- **reduced-motion:** анимации и переходы отключены, плавная прокрутка и прокрутка в `app.js` мгновенные.
- **reduced-transparency и браузеры без `backdrop-filter`:** стекло заменяется почти непрозрачным фарфором (`@supports not` и `prefers-reduced-transparency`). **Визуально в браузере без `backdrop-filter` не проверялось** — только правилами CSS и тестом их наличия.
- **forced-colors:** границы панелей и выделение выбранных кнопок через системные цвета.

## Риски и что проверить в браузерном QA

1. **Индикатор подключения.** Если какой-то браузер сериализует встроенный цвет иначе, чем `#hex` или `rgb(r, g, b)`, точка останется серой «проверкой». Текст состояния при этом верный. Проверить Safari iOS в обоих состояниях.
2. **Редактор с реальным изображением.** Обрезка, разделитель, увеличение, история, экспорт — по коду классы сохранены, но с живыми данными я не смотрел.
3. **Липкий редактор на низких окнах** (около 700 px) вместе с панелью цвета: возможно, придётся уменьшить `54vh`.
4. **Публикация Pages из `codex/site`** должна включать папку `pages/assets/`.
5. **Шапка в онлайн-режиме на 361–420 px** близка к пределу. Если текст «Ссылка на студию» станет длиннее, потребуется перенос.
