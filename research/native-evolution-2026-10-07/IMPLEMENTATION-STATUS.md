Скрипт идемпотентен: `python3 ios/tools/build_catalog.py [--archive PATH] [--no-images]`.

**Результат:**
- **305 карточек.** 300 уникальных `product_id` плюс 5 зеркал (Ombra Х/О/Ю, Armonia О/Ю): у них в инвентаризации нет `product_id`, id взят из кнопки корзины самой карточки (`data-id`). Лендинги `new/detail` пропущены — это не продаваемые карточки.
- **539 исполнений.**

| Исполнение | Количество |
|---|---|
| S-Stone матовое | 219 |
| S-Sense глянцевое | 171 |
| S-Sense матовое | 65 |
| остальное (МДФ, Solid Surface, Gelcoat, керамогранит, металл, пластик, без данных) | остальные |

**Правила разбора:**
- **Исполнения** берутся из данных конфигуратора (`base_variants`: материал, покрытие, цена).
- **Артикулы** — только из панели конфигуратора своего материала (`data-articule-tab`), с границей до следующей панели или до блока характеристик и карточек похожих товаров, без фиксированного среза строки.
  - Артикул привязывается к исполнению по суффиксу: `…G` — глянцевое, `…M…` — матовое.
  - `…F` — артикул заказного цвета RAL.
  - Если артикула на странице нет (пример: матовое S-Sense у Ornella), он остаётся `null` и в интерфейсе показывается «уточняется у менеджера».
- **Характеристики** — только из элементов `data-tab-content="optN"` главной карточки (сбалансированные `<div>`).
  - `optN` сопоставляется с материалом, поэтому вес у Aria разный по исполнениям: 144 / 133 кг.
  - Блоки «похожих товаров» не читаются.
  - Вкладки без материала (формы зеркал) не перезаписывают первый блок.
- **Размеры — точные числа или диапазоны с карточки.** Пример — Альда угловая Л 160×70: длина 1715–2015, ширина 805–1105 мм. Из названия размер не выводится.
- **Категории:** зеркала — отдельная категория «Зеркала», по URL `zerkala` или по полю «Тип: Зеркало…». Опции и кастомизация помечены `isOption`, в каталоге они видны только по включённому фильтру.
- **Документы:** без дублей по URL, разделены по видам: паспорт, чертёж, 3D, презентация, опция, прочее. Платные доработки («Изготовление технического отверстия…») в карточке вынесены в «Доработки по запросу».
- **Изображения:**
  - фото есть у 302 из 305 карточек — первая официальная фотография, JPEG до 1100 px, итого ~28 МБ;
  - `imageSource` — URL того файла, который фактически выбран;
  - картинок нет у 3 карточек.
- **Сопоставление со старыми id:** aria → 20645, opera → 30897, greca → 1120, opera-top → 30919.
- **3D-модели:** у 10 карточек есть официальная USDZ, она указана в поле `model`. Сами модели будут добавлены в bundle в итерации 2.

**Найденные расхождения источника (не исправлялись, зафиксированы):**
- У части угловых ванн цена в кнопке корзины отличается от цены конфигуратора. Пример — Альда угловая Л 160×70: 453 000 против 435 300. Берётся цена конфигуратора (исполнение и цена связаны).
- Левые и правые угловые модели делят один артикул (101924MN и т. п.) — так на сайте. Поиск по такому артикулу возвращает обе карточки.
- В поле «Тип» встречается «180 см» у модели 160×70 — показывается как на сайте только в данных, в интерфейс не выводится.

### Checkpoint 1.1 — исправления по ревью Codex ✅ (компилируется)

1. **Фильтры по исполнению.** Материал, поверхность и цена проверяются на **одном и том же** исполнении (`CatalogFilter.allowedVariants`). Результат несёт ключ самого дешёвого подходящего исполнения: цена в сетке, сортировка и открытая карточка берутся у него. Aria больше не проходит фильтр «S-Stone + до 800 000». Поиск по артикулу исполнения, которое отфильтровано, ничего не находит. Тест: `testVariantFiltersHoldForOneExecutionAndShowItsPrice`.
2. **RAL.**
   - `ProjectLine.total` для цветной строки — `nil`, текст «базовая сумма + цвет по запросу»;
   - артикул — только опубликованный `…F`; если его нет — «артикул цвета уточняется», белый артикул не подставляется;
   - итог проекта показывается как «Базовая сумма… Итог неполный»; так же во временном PDF.
3. **Стабильный ключ исполнения** — `id` из сборщика: `material-finish-порядковый номер`, без цены и артикула. Неизвестный ключ даёт `nil` и строку «Исполнение требует уточнения». Если исполнений несколько, `variant(key: nil)` ничего не выбирает неявно. Тест: `testVariantKeysAreStableAndUnknownKeysAreNotSubstituted`.
4. **Сохранность проектов.**
   - перед каждой записью предыдущая читаемая версия копируется в `projects.backup.json`;
   - нечитаемый `projects.json` не перезаписывается: копируется в `projects.unreadable-<время>.json`, состояние восстанавливается из резервной копии; миграция пустых данных поверх него не выполняется;
   - `add` с количеством ≤ 0 или с неизвестным исполнением возвращает `nil` и ничего не меняет.

   Тест: `testUnreadableProjectsFileIsQuarantinedAndRecoveredFromBackup`. Отрицательное количество проверяется в `testProjectsPreserveDistinctExecutionsAndPersist`.
5. В `build_catalog.py --no-images` больше не теряются ссылки на уже собранные фото.

## Checkpoint 2 — студия материалов (compile-ready, ждёт визуального QA)

**Студия.** Тот же код (`MaterialStudioScene.swift`) компилируется под iOS и macOS. Свет, PBR и камера настраивались по офскрин-рендерам `SCNRenderer` на Mac — симулятор не запускался; контрольные кадры есть в scratchpad Opus.

**Сцена:**
- официальная USDZ без изменения геометрии: масштаб, центрирование, длинная ось по X;
- бесшовная графитовая циклорама без линии горизонта;
- процедурное HDR-окружение: верхний софтбокс, четыре вертикальные полосы, низкая полоса-отражатель;
- ключевой направленный свет с мягкой тенью, HDR-камера, лёгкая виньетка, без bloom.

**Поверхности** (иллюстрация отклика на свет, не измеренные BRDF):

| Исполнение | roughness | clearCoat |
|---|---|---|
| S-Stone | 0,74 | — |
| S-Sense матовое | 0,5 | 0,45 / roughness 0,42 |
| S-Sense глянцевое | 0,32 | 1,0 / roughness 0,025 |

На глянце софтбоксы дают чёткие полосы, на матовом — мягкий градиент.

**Ракурсы:**
- «Вся форма» — 3/4;
- «Борт крупно» — ближе к краю, ванна остаётся узнаваемой, лёгкая глубина резкости.

**Модели в bundle** (`CatalogMedia/models`, официальные файлы без изменений): Noemi 170, Ornella 170×75, Cascata 180×80, Sofia 150/165/170/185, Mona 170, Alda 160×70, Orlanda 160×70, Luce, Ninfea. Greca берётся из Resources. `CatalogMedia` весит 63 МБ (фото 28 МБ, модели ~35 МБ).

**Главная — `MaterialFeatureView`** (вариант B):
- один крупный журнальный блок: «Материалы Salini», «Свет на камне.», лид;
- рендер Noemi «борт крупно» высотой 430 pt;
- свет медленно дрейфует только когда блок виден; при Reduce Motion неподвижен;
- две кнопки — только реальные исполнения Noemi (S-Stone матовое / S-Sense глянцевое), без отключённого третьего;
- факт состава одной строкой;
- «Студия материалов».

**Полная студия — `MaterialStudioController`** (A + B):
- **Форма:** меню из официальных моделей с перечислением их исполнений.
- **Режим:** «Сравнение» / «Одно исполнение». Сравнение — два рендера одной формы и одного света; правый открывается от шва. Шов двигается **отдельным доступным слайдером «Граница»**, а не жестом по рендеру. Подписи сторон — на рендере.
- **Исполнения слева и справа** — только существующие у формы. Матовое S-Sense изучается на Ornella и Cascata.
- **Слайдер «Свет»:** поворачивает ключевой свет и окружение вместе.
- **Переключатель «Вся форма / Борт крупно»:** камера переезжает плавно, при Reduce Motion мгновенно.
- **Цвет:** «Базовый белый» и 30 кодов RAL Classic с подписью «экранное приближение; Salini заявляет 216 цветов; доступность и цену подтверждает менеджер».
- **Структура:** честная увеличенная схема (`StructureDiagram`). S-Stone — однородная масса; S-Sense — основа и Gelcoat 0,8 мм с пометкой «масштаб условный». Отсечение реальной сетки не используется.
- **Факты:** состав, уход (можно / нельзя), гарантия по типам изделий — из FAQ Salini.
- **Применение:** «{форма} · {исполнение} · цена» открывает карточку именно этого исполнения; «Все изделия: {исполнение}» открывает каталог с этим фильтром (`CatalogController.preset`).

**Жизненный цикл:**
- модель загружается вне главного потока, с индикатором;
- `rendersContinuously = false`;
- дрейф света через `CADisplayLink` только для видимого блока, остановка вне окна и при Reduce Motion.

**Ограничения и что проверить визуально:**
- Два `SCNView` в режиме сравнения — это двойной рендер одной модели до 55 тыс. граней. Проверить fps на устройстве.
- Проверить, что статичный `SCNView` (без `isPlaying`) перерисовывается после смены исполнения или цвета на симуляторе. Если нет — включить `rendersContinuously` на время взаимодействия.
- Цвет RAL — экранные приближения 30 популярных кодов, а не вся палитра Salini: коды по материалам из PDF-палитр извлекаются с ошибками и не использованы.
