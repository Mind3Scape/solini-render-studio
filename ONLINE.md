# Веб-студия

Постоянная входная страница: https://mind3scape.github.io/solini-render-studio/.
Для друзей используйте **полную ссылку-приглашение**, которую показывает команда запуска
или кнопка «Ссылка на студию» внутри программы. Код приглашения не опубликован в GitHub.
Другу не нужно устанавливать Python, модели или приложение: достаточно браузера.

## На Mac владельца

Веб-служба уже настроена для репозитория `Mind3Scape/solini-render-studio`.
Запускается автоматически при входе в macOS. Mac должен быть включён, не спать
и иметь интернет; при закрытой крышке обработка обычно недоступна.
После перезапуска обновление входной страницы может занимать несколько минут.

- **Запустить веб-студию.command** — включить службу и автозапуск, вывести приглашение.
- **Остановить веб-студию.command** — остановить службу и выключить её автозапуск.
- `.venv/bin/python -m salini.online_host link` — ещё раз вывести приглашение.

Закрытие вкладки не останавливает службу. Не переносите папку проекта и не удаляйте
`.venv`, пока служба включена. После перемещения запустите команду запуска из новой папки.
Служба хранится в `~/Library/LaunchAgents/local.salini.online.plist`.
Локальная программа на порту 8765 работает отдельно.

Посетители выбирают уже установленные на Mac модели. Чтобы добавить модель,
владелец один раз запускает её в локальной программе. После этого она становится доступной
на сайте. Модели из исследовательского раздела без адаптера остаются справочными.

## Что происходит с данными

GitHub Pages показывает входную страницу и переводит браузер на защищённое соединение
Cloudflare Tunnel с Mac. Сам GitHub не обрабатывает изображения. Изображения проходят
через Cloudflare и сохраняются на Mac владельца, который имеет к ним доступ.
Открытого доступа к локальной истории, папкам компьютера и журналам через сайт нет.

Каждый браузер получает свою историю. Другие посетители её не видят. Приватный ключ
посетителя хранится в браузере на входной странице, поэтому история сохраняется при
смене адреса туннеля. Очистка данных браузера или другой браузер создают новую историю.
Передавайте друзьям ссылку кнопкой «Ссылка на студию» — она содержит только приглашение.

Веб-данные: `~/Library/Application Support/Salini Render Studio/online/`.
Здесь находятся `uploads`, `jobs`, журналы `logs`, приватный файл `secrets.json`
и служебное состояние соединения. Эти файлы не входят в Git и ZIP.
Локальные модели остаются в общей папке приложения и используются обеими версиями.

Ограничения веб-версии: 20 МБ / 20 мегапикселей на загрузку, обработка до 768 px,
30 исходных изображений на посетителя, 12 запусков в час на посетителя,
не более 6 задач одновременно в очереди. GPU обрабатывает одну задачу за раз,
включая задачи локальной программы. При заполнении веб-хранилища новыми PNG
примерно до 2 ГБ или остатке диска менее 5 ГБ загрузка приостанавливается.

Данные автоматически не удаляются. При необходимости владелец останавливает службу,
сохраняет нужные результаты и освобождает место в папках `online/uploads` и `online/jobs`.
Не публикуйте `secrets.json`. Для смены приглашения остановите службу, сохраните копию
этого файла вне проекта и переместите оригинал из папки `online`, затем запустите службу:
старое приглашение и сеансы перестанут действовать, старая веб-история потребует доступа владельца.

## Устройство и обслуживание

- Исходный код: ветка `main`; входная страница: ветка `codex/site`.
- Сервер FastAPI слушает только `127.0.0.1:8767`.
- Исходящий Cloudflare Quick Tunnel предоставляет HTTPS-адрес без настройки роутера.
- После запуска служба записывает новый адрес в публичный `connection.json` ветки
  `codex/site` через установленный и авторизованный GitHub CLI `gh`. Там нет приглашения.
- GitHub Pages публикует страницу и актуальный адрес. Посетитель переходит на живую студию.
- Если Mac недоступен, входная страница объясняет это и повторяет проверку раз в 30 секунд.

Это бесплатная экспериментальная схема, рассчитанная на небольшое число знакомых.
[Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)
не гарантируют постоянную доступность. Платный сервер или домен не подключены.

Для новой установки владельцу нужны рабочая локальная программа, скачанные модели,
GitHub CLI с доступом к указанному репозиторию и включённый GitHub Pages для `codex/site`.
При развёртывании собственного форка измените `REPOSITORY` в `online_host.py` и
`PAGE_URL` в `online_app.py`. Посетителям GitHub CLI и аккаунт не нужны.

Для обновления входной страницы скопируйте содержимое `pages/` в отдельную рабочую копию
ветки `codex/site`, **сохранив её текущий `connection.json`**, сделайте commit и push.
Обновление `main` само по себе не меняет входную страницу. Для обновления сервера
остановите веб-службу, обновите исходники и запустите её снова.

Диагностика: `online/logs/host.log`, `server.log`, `tunnel.log`.
Проверка локального сервера: `curl http://127.0.0.1:8767/health`.
Сам `/api/status` требует сеанс приглашённого посетителя.
