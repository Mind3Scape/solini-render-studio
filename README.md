# Salini Render Studio 1.1

Локальная программа для Mac с чипом Apple: превращает изображение из конструктора в более реалистичную предметную визуализацию. Выбор моделей, шесть вариантов света, шесть вариантов цвета, регулировка силы и сравнение «до/после». NVIDIA, платные API, аккаунты и Codex для запуска не нужны.

## Запуск и передача программы

1. Распакуйте **всю папку** в удобное место, например «Документы».
2. Дважды нажмите **Установить Salini.command**. Установщик загрузит Python и зависимости; нужен интернет.
3. Откроется программа в браузере по локальному адресу `http://127.0.0.1:8765` (если порт занят, выбирается следующий).
4. В дальнейшем открывайте **Salini Render Studio.app** или **Запустить Salini.command**. Приложение `.app` должно оставаться рядом с остальными файлами папки.

Для передачи отправьте `Salini-Render-Studio-Mac.zip`. Архив не содержит ваших изображений, истории, моделей или аккаунтов. Получатель устанавливает зависимости и скачивает только выбранные им модели.

Это локальная сборка без нотариальной подписи Apple. Если macOS блокирует скачанный установщик, можно запустить его из Terminal: наберите `/bin/zsh `, перетащите в окно файл `Установить Salini.command` и нажмите Enter. Не требуется отключать Gatekeeper или другие системные защиты.

Apple M1 или новее. **macOS 14+ для Klein и FIBO; macOS 26+ для моделей GGUF и Real-ESRGAN** из-за требований готового движка. Проверено на M4 Pro / 24 ГиБ / macOS 27. Для установки зависимостей и Klein 4B стоит иметь 25 ГБ свободного места. Остальные модели занимают дополнительное место по таблице ниже. При нехватке памяти программа объясняет ограничение до скачивания.

## Работа с изображением

1. Загрузите PNG, JPG, WebP или TIFF до 40 МБ / 40 мегапикселей. PDF сначала экспортируйте в картинку.
2. Если это лист согласования, нажмите **Выделить область рендера** и обведите изделие с небольшим полем. Таблицы, надписи и подписи оставьте за рамкой.
3. Выберите модель в постоянно видимом списке. Для начала подойдёт **Klein 9B KV / 768 px** на Mac с 24 ГБ; на 16 ГБ — **Klein 4B**. Для новых моделей GGUF автоматически выбирается 512 px, для Real-ESRGAN — 1024 px.
4. Выберите **свет при генерации**: бережный, студийный, дневной, тёплый, контрастный или светлый каталог. Эти варианты задают разные направления, температуру и характер света. Для изменения света нажмите **Сделать реалистичнее** ещё раз: это новая AI-обработка.
5. При первой обработке выбранная модель и нужный движок скачаются автоматически. Видны текущий компонент и этап работы; уже загруженные компоненты используются повторно. Остальные модели не скачиваются. После успешной первой обработки можно работать офлайн.
6. На готовом результате выбирайте **цвет**: нейтральный, тёплый, холодный, насыщенный, мягкий, контрастный. **Сила цвета** от 0 до 100% плавно меняет этот эффект. Нейтральный вариант сохраняет цвета AI-результата при любой силе. Эти изменения применяются без запуска модели.
7. **Сила всей обработки** смешивает оригинал и обработанный результат: 0% — исходный рендер, 100% — AI-результат с выбранным цветом. При изменении формы моделью промежуточные значения могут давать двойные края; проверьте их увеличением.
8. Двигайте разделитель или ползунок под изображением. Кнопки `+` / `−` увеличивают обе картинки вместе; увеличенное изображение можно перемещать мышью. Клавиши ← / → у разделителя тоже работают.
9. Если модель изменила деталь, нажмите **Вернуть деталь из оригинала**, обведите её и нажмите **Вернуть оригинал**. Внутри участка возвращаются исходные пиксели; узкая граница плавно смешивается. Цветовые настройки сохраняют восстановленные участки. Можно восстановить несколько областей или сбросить исправления.
10. Сохраните PNG или нажмите **Поделиться**. Дождитесь надписи «Сохранено» после изменения цвета.

**Интерактивное сравнение** — один HTML-файл с обеими картинками и разделителем, открывается в браузере без программы и интернета. **Исходный лист с новым рендером** — PNG с неизменёнными пикселями вне выделенного прямоугольника (относительно загруженного, ориентированного и приведённого к RGB оригинала). PNG, лист и сравнение содержат текущие цвет и силу эффекта. История сохраняет эти настройки; повторное открытие результата восстанавливает их. Исходный результат модели хранится отдельно, поэтому изменения цвета не накапливаются.

Они не выдаются за работающие редакторы JPG на Mac.

## Проверенное качество и скорость

На предоставленном рендере тумбы (область 887 × 633, Klein обрабатывает 768 × 560 с полем, 4 шага, seed 42):

| Модель | Время M4 Pro / 24 ГиБ | Пиковая память MLX | Наблюдение |
|---|---:|---:|---|
| Klein 4B Q4 | 33,9 с | 7,69 ГиБ | Улучшила свет, но добавила лишнее отверстие в чаше |
| Klein 9B KV Q4 | 32,6 с | 19,41 ГиБ | На этом примере лучше сохранила чашу и отверстие |
| Qwen Image 2.1 Q4, 512 px | 755,7 с | Не измерялась | Улучшила свет, заметно изменила углубления между фасадами |
| FIBO Edit 1.5 Q4, 512 px | 246,9 с | 15,41 ГиБ | Запускается, но на этом примере изменила ракурс, фасады и отверстия |
| Real-ESRGAN, 512 px | 52,4 с | Не измерялась | Восстановление деталей; исходное освещение сохраняется |

Повторный запуск 9B с отключённым доступом Hugging Face / Transformers к сети занял 49,2 с с тем же пиком памяти. Это измерения одного изображения, не общий рейтинг. Для LongCat, Qwen Edit 2511 и FireRed дополнительно проверена загрузка компонентов и проход через кодирование, один шаг модели, декодирование и экспорт при 512 px. Все три завершились успешно; одношаговые проверки не оценивают качество полного прогона. Память MLX не равна полной памяти системы. Новые редакторы с 30–40 шагами могут работать несколько минут. Размер 1024 px требует больше памяти.

Это генеративное редактирование, а не точный физический рендер или реконструкция CAD. Модель может изменить пропорции, отверстия, оттенок и рисунок шпона. Инструкция на сохранение конструкции не даёт математической гарантии. Восстановление участка сохраняет исходную деталь, но может оставить различие света на границе. Без фотографий готового изделия модель не знает реального блеска и цвета конкретного покрытия. Цветовые ползунки — художественная коррекция, не калибровка RAL.

## Данные и обслуживание

Все загрузки, история, модели и журналы находятся в `~/Library/Application Support/Salini Render Studio/`.

Изображения не отправляются внешним сервисам. Установщик обращается к PyPI и источнику Python через uv; модели скачиваются с Hugging Face / официальных GitHub Releases, готовый движок — из официального выпуска stable-diffusion.cpp. Сервер слушает только `127.0.0.1`.

Закрытие вкладки не прерывает обработку. Для отмены есть кнопка **Отменить обработку**. Повторный запуск открывает уже работающий экземпляр. Фоновый сервер прекращает работу при перезагрузке Mac и не добавляется в автозагрузку. Журнал приложения: `logs/server.log`; журнал конкретной ошибки можно скачать из интерфейса.

Модели закреплены на ревизиях, движок — на версии и SHA-256, зависимости — в `uv.lock`. Для повторной установки зависимостей запустите **Установить Salini.command**. Не удаляйте `.venv` во время работы. Чтобы освободить место, сначала завершите обработку и сервер, затем удалите ненужные файлы из папки данных.

## Для разработки

- Python 3.12, FastAPI, собственный HTML/CSS/JavaScript без внешних CDN.
- MFLUX 0.19.2 / MLX для Klein и FIBO; stable-diffusion.cpp `c678dfe` / Metal для GGUF и Real-ESRGAN.
- Изолированная группа процессов на обработку; отмена останавливает также дочерний движок.
- Проверка: `.tools/salini-uv sync --frozen --python 3.12 --managed-python`, затем `.venv/bin/python -m pytest -q`.
- Упаковка: `.venv/bin/python scripts/package.py`.
- Другая папка данных: переменная окружения `SALINI_DATA_DIR`.
